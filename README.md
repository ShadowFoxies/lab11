## Завдання

### 1. Базовий клас `DMAChannel`

Розробити у модулі `hardware_entities.py` базовий клас `DMAChannel` для моделювання каналу контролера DMA з інкапсульованими приватними полями (`__channel_id`, `__priority`, `__transfer_buffer`). Реалізувати доступ і валідацію пріоритету (`0..7`) через декоратори `@property` та `@setter`, а також базові методи `__init__`, `__str__`, `__repr__` та `__eq__`.

### 2. Похідний клас `ScatterGatherDMA`

Реалізувати клас-нащадок `ScatterGatherDMA`, що успадковує `DMAChannel` з делегуванням конструктора через `super().__init__()`. Додати обмеження таблиці дескрипторів (`__descriptor_limit`), список дескрипторів (`__descriptors`), метод реєстрації нового сегмента `register_descriptor()` та перевизначити рядкові представлення `__str__` і `__repr__`.

### 3. Перевантаження dunder-методів та тестовий стенд

Забезпечити перевантаження оператора додавання `__add__` (`+` для конкатенації ланцюжків передачі пам'яті), оператора порівняння `__lt__` (`<` за пріоритетом каналу) та протоколу послідовностей (`__len__`, `__getitem__`). У модулі `test_bench.py` виконати перевірку всіх методів, валідації сетерів та поліморфного сортування каналів через `sorted()`.
